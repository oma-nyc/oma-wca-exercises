## IT Automation Architect custom mode

Prompt: Create a new Plan mode specifically for generating IT Automation content. This would be the same as your normal Plan / Architect mode but with enhanced knowledge about Ansible, Ansible Automation Platform, Ansible module development with Python, and everything in the Hashicorp suite including Terraform, Packer, Vault, Nomad, Consul, Boundary, and Waypoint. Also include enhanced knowledge on Cloud infrastructure services management with tools like AWS CloudFormation and Azure Biceps.

## IBM MQ - OpenShift - HCP Vault

Prompt: Help me build a complete and reusable Ansible role that deploys IBM MQ on OpenShift 4.18. The tasks shall be maintained in separate YAML files, with a main.yml that uses includes, instead of one monolithic tasks/main.yml. Hashicorp Vault shall be used for securing credentials. Help me define the directory structure for the role using as few commands as possible. Instrument the role to be updated by a team instead of one person.
